# 2026-09-07 — выкат v0.12.4

Выпуск по внешним обращениям: один запрос на слияние и две задачи, лежавшие в
репозитории без ответа (#42 — с 24 июля, #43 и PR #44 — с 28 июля).

**Что вошло.**

1. PR #44 от stolpov — комментарии не показывались в карточке задачи. Принят
   почти как есть. При разборе выяснилось, что поломка шире заголовка: bd 1.1.0
   помечает каждую запись выгрузки полем `_type":"issue"`, а прежний фильтр
   `is_non_issue_record` считал служебной любую запись, где поле `_type` вообще
   есть. То есть чтение из JSONL возвращало ноль задач, а пересчёт статусов
   эпиков не делал ничего. Урок записан в память bd под ключом
   `bd-1-1-0-bd-export-beads-issues`.
2. Задача #42 — панель агентов падала на обычных записях `tools:` и `model:`.
   Автор назвал два пути падения, при разборе нашёлся третий и самый частый:
   отсутствие строки `tools:` вовсе. Подробности — в
   `2026-09-07-agents-panel-frontmatter.md`.
3. Доска обёрнута в `ErrorBoundary` — `2026-09-07-board-error-boundary.md`.
4. Опрос сервера снова читает приращением, полное чтение только при изменении
   числа комментариев — `2026-09-07-polling-comment-counts.md`.
5. Мелочи: `.worktrees` исключён из проверки типов; переключатель «все
   инструменты» заменён односторонней кнопкой.

**Порядок сработал как в прошлый раз.** Версия в пяти файлах, `Cargo.lock`
правился с привязкой к строке `name = "beads-server"` — рядом снова лежала
посторонняя зависимость с похожим номером. После отправки в `main` задание
`ci.yml` дописало коммит `Update Nix dependency hashes` (`package-lock.json`
менялся при подъёме версии) — его забрали ДО метки, метка встала на него.

**Что не сломалось в этот раз.** Задание winget прошло с первого раза:
синхронизация ответвления, добавленная в `release.yml` после 0.12.3, сработала.
Прошлый выпуск на этом месте падал.

**Что проверить, если сломается в следующий раз.** Сборка Nix идёт 5–15 минут и
занимает единственного исполнителя: новый толчок в `main` отменяет предыдущий
запуск. Если торопиться и отправить ещё коммит, отменится и тот запуск, который
должен был дописать хеш зависимостей.

**Что намеренно не трогали.** Выбор отдельных инструментов в панели агентов —
это новая возможность, а не починка.
