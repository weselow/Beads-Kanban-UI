# 2026-09-07 — снятие пометки «winget скоро будет» (beads-web-5bp)

Заявка на winget принята: PR microsoft/winget-pkgs#402396 слит 2026-07-29,
в каталоге лежат обе версии — 0.11.2 и 0.12.2. Значит команда
`winget install weselow.beads-web` работает, и цитата-предупреждение из
README.md и README-ru.md убрана. Заодно в русский README добавлена строка про
`SHA256SUMS.txt`, которая была только в английском.

**Что проверить, если сломается.** Если пользователи жалуются, что winget не
находит пакет, — сначала посмотреть, есть ли нужная версия в каталоге:
`gh api repos/microsoft/winget-pkgs/contents/manifests/w/weselow/beads-web`.
Манифест не обновляется сам: на каждый новый выпуск нужна отдельная заявка,
и пока её не приняли, `winget install` ставит предыдущую версию.

**Что намеренно не трогали.** Автоматическую отправку манифеста в winget при
выпуске — сейчас это ручной шаг, и он таким и остался.
